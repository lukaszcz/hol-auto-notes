# Final integrity procedure

`PACKAGE-INVENTORY.tsv` is generated by the retained typed, symlink-aware
`inventory.py` and excludes only itself and checksum self.  The final
`checksums.sha256` hashes every regular file except itself, including the
inventory.  The final external status-bearing verification runs
`sha256sum -c checksums.sha256` from package root after recursive read-only
sealing; it creates no package byte.
