## 1. Isabelle implementations

### 1.1 `linarith` / `arith`

**Core engine** — `src/Provers/Arith/fast_lin_arith.ML` (Nipkow, Weber, Böhme). The `Fast_Lin_Arith` functor is a proof-producing **Fourier–Motzkin variable-elimination** refuter, explicitly "Code ported from HOL Light". The untrusted phase runs FM elimination on `lineq` records (`Lineq of int * lineq_type * int list * injust`), choosing elimination variables to minimize blowup (equations first, by minimal |coefficient|); rational coefficients are normalized to integers via LCM of denominators (`integ`). Each derived inequality carries a **justification tree** `injust` (`Asm | Nat | LessD | NotLessD | Multiplied | Added`) — i.e. the nonnegative multipliers of a Farkas-style certificate. `mkthm` replays the certificate in the kernel: assumption lookup, `add_thms` (monotonicity), `mult_thm` (scaling), then simplification. `refute` orchestrates case splitting (`split_items` / `elim_neq` for `≠` premises, bounded by `neq_limit`, default 9); discreteness flags let it round for `nat`/`int` (a `<` becomes `≤ −1` etc.), so it decides more than pure rational reasoning but is deliberately incomplete for full integer arithmetic.

**HOL preprocessing** — `src/HOL/Tools/lin_arith.ML` (Weber, Nipkow). `decomp` maps atoms into (coeff-list, const, rel, discrete-flag) form for any `linordered_idom` plus registered *discrete types*; `add_inj_const` handles `int-of-nat` style injections (unwrapped by `demult`). Non-linear operators are removed by pre-splitting (`split_once_items`, limit `split_limit` = 9): `min`, `max`, `abs`, `nat` coercion, nat subtraction, `div`/`mod` on nat and int. Entry points `lin_arith_tac`/`tac`; also wrapped as a **simproc** so the simplifier discharges linear side conditions automatically.

**`arith` method** — `src/HOL/Tools/arith_data.ML` maintains a Theory_Data registry (`Arith_Data.add_tactic`); the `arith` method inserts `[arith]`-tagged facts and chained facts, then runs `FIRST'` over the registered tactics in registration order — in stock HOL that is **linarith (with full splitting) then `presburger`** (`cooper.ML` registers itself via `Arith_Data.add_tactic "Presburger arithmetic" (tac true [] [])`).

**Papers**: Chaieb & Nipkow, *Proof Synthesis and Reflection for Linear Arithmetic*, JAR 41:33–59 (2008), DOI 10.1007/s10817-008-9101-x (covers proof-producing vs reflected linear QE; reflection 1–2 orders of magnitude faster). The FM engine itself descends from Harrison's HOL Light `REAL_ARITH` (*Theorem Proving with the Real Numbers*, 1998). Note: **`linarith` today is still FM, not simplex** — the simplex implementation in Isabelle (`src/Tools/Argo/argo_simplex.ML`) backs only the separate `argo` method.

### 1.2 `presburger`

**Production method** — `src/HOL/Tools/Qelim/cooper.ML` (Amine Chaieb): **proof-producing ML conversions implementing Cooper's algorithm**, *not* reflection, in default mode. Pipeline (from the source):
1. Atomize (`Object_Logic.full_atomize_tac`), simplify, generalize non-Presburger int/nat subterms, thin irrelevant premises.
2. `div_mod_tac` + `splits_tac`: eliminate `mod`/`div`/`abs`/`min`/`max` via `split_zdiv`, `split_zmod`, `mod_eq_0_iff_dvd`, etc.; `nat_to_int_tac` coerces `nat` goals to `int`.
3. `linearize_conv` normalizes atoms to linear form (rejects variable products: `COOPER "not linear"`); `unify` scales all coefficients of the QE variable to their LCM (`Integer.lcms`, `unity_coeff_ex`).
4. Core QE `cooperex_conv`: builds the minus-infinity/plus-infinity virtual substitution (`decomp_minf`/`decomp_pinf`), computes **B-sets/A-sets** (picking the smaller: `if length bl <= length al`), the divisibility period (LCM of `dvd` divisors, certified via a `divprop` theorem table), and produces the finite disjunction — every step a kernel-checked conversion.
5. **Hybrid escape hatch**: under `quick_and_dirty`, `procedure` reifies the formula into the datatype of `Cooper_Procedure` (`src/HOL/Tools/Qelim/cooper_procedure.ML` — SML **code-generated from the verified formalization** `src/HOL/Decision_Procs/Cooper.thy`, main function `pa : fm -> fm`) and certifies the answer by **oracle**.

So: the *verified/reflected* Cooper exists (Cooper.thy, per Chaieb & Nipkow LPAR 2005: reflection gave a ~200x speed-up over LCF-style), but in the main image it is used only as an oracle under `quick_and_dirty`; the trusted default path is proof-producing conversions. Separately, `src/HOL/Decision_Procs/cooper_tac.ML` provides an oracle-based tactic (`linzqe_oracle`) in the HOL-Decision_Procs session. Method setup lives in `src/HOL/Presburger.thy` ("Cooper's algorithm for Presburger arithmetic", `elim`/`add:`/`del:` options, `[presburger]` lemma attribute covering `mod`/`div`/`dvd`/parity).

**Papers**: Chaieb & Nipkow, *Verifying and reflecting quantifier elimination for Presburger arithmetic*, LPAR 2005, LNCS 3835:367–380; and JAR 2008 (above).

### 1.3 `algebra` (Gröbner bases)

`src/HOL/Tools/groebner.ML` (Chaieb) — follows Harrison's HOL Light `GROEBNER` design. Untrusted Buchberger algorithm over `Rat.rat` coefficients with a proof-history datatype (`Start`, `Mmul`, `Add`); `grobner_refute`/`resolve_proof` extract **cofactor certificates** (weak-Nullstellensatz linear combinations: scaling constant + cofactor polynomials such that Σ cᵢ·pᵢ = the contradiction polynomial); certificates are checked in-kernel by **ring normalization**, never by trusting the Gröbner computation. Negated equations use the **Rabinowitsch trick** (`grobner_strong`: fresh variable z, polynomial `z·p − 1`). Field division/inverse are parsed and pushed into polynomial form (`field_dest_div`/`field_dest_inv`). Entry points: `ring_tac` (universally quantified equalities/implications between equalities over comm. semirings/rings/fields), `ideal_tac` (existential ideal-membership witnesses via `multi_ideal`/`solve_idealism`), `algebra_tac = ring_tac ORELSE ideal_tac`. Theory-class hookup comes from `Semiring_Normalizer` context data (`is_const`, `dest_const`, `mk_const`, `ring_eq_conv`).

**Paper**: Chaieb & Wenzel, *Context aware Calculation and Deduction — Ring Equalities via Gröbner Bases in Isabelle*, Calculemus/MKM 2007, LNAI 4573.

### 1.4 Ring/field normalization; `ferrack`/`mir`

- `src/HOL/Tools/semiring_normalizer.ML` (Chaieb) — Harrison-style **semiring normalizer**: conversion-based canonical polynomial form, parameterized per algebraic class via context data (semiring: 5 ops + 36 rules; ring: 2 + 2; field: 2 + 2; idom: 2 rules; ideal thms). Entry points `semiring_normalize_conv`, `semiring_normalize_ord_conv`, `semiring_normalizers_conv`. This is the checker used by `groebner.ML`.
- `algebra_simps` (named_theorems, declared in `src/HOL/Groups.thy`) and `field_simps` (`src/HOL/Fields.thy`: "rewrite rules to eliminate divisions") are simp-set collections, not decision procedures; `ring_simps` is the pre-2009 name of `algebra_simps`.
- `src/HOL/Decision_Procs/` is the **verified/reflected QE zoo**: `Cooper.thy`, `Ferrack.thy` (Ferrante–Rackoff for linear real arith), `MIR.thy` (mixed integer/real, with floor), `Dense_Linear_Order.thy` + `ferrante_rackoff.ML`/`langford.ML` (generic DLO QE), `Parametric_Ferrante_Rackoff.thy`, `Commutative_Ring.thy` (reflected ring), `Reflected_Multivariate_Polynomial.thy`, `Approximation.thy`, plus oracle tactics `cooper_tac.ML`, `ferrack_tac.ML`, `mir_tac.ML`. **In practice** these are a separate session (demo/research grade); everyday users get `linarith`/`arith`/`presburger`/`algebra` from Main. The DLO instance (`dlo`/`ferrack` method infrastructure via `ferrante_rackoff_data`) is the most reused piece.

### 1.5 `argo`, `smt`, `metis` (context)

- **argo** — `src/Tools/Argo/` (argo_core/cdcl/cc/simplex/proof…, by Sascha Böhme) with HOL binding `src/HOL/Tools/Argo/argo_tactic.ML`: a native-ML SMT-like solver (CDCL SAT + congruence closure + **simplex** for linear real arithmetic) that emits proof traces replayed through the kernel. It is a separate `argo` method (in `try0`'s repertoire); it does *not* replace `fast_lin_arith` behind `linarith`.
- **smt** — external Z3/CVC/veriT with full LCF-style proof reconstruction: Böhme & Weber, *Fast LCF-Style Proof Reconstruction for Z3*, ITP 2010, LNCS 6172. Slots in as the heavyweight quantifier-capable backend, mostly reached via Sledgehammer.
- **metis** — Hurd's ordered-paramodulation FO prover run internally with source-level reconstruction (Paulson & Susanto 2007); it is the ecosystem's *reconstruction* workhorse for Sledgehammer, not an arithmetic procedure (no built-in arithmetic theory).

## 4. Techniques to close the gaps (from the literature)

1. **Verified + reflected Presburger / linear QE** (gap: fast `presburger`, real QE): formalize the algorithm, prove `⊨ pa(φ) ⟷ φ`, execute by evaluation. Chaieb & Nipkow LPAR 2005 (~200x over LCF-style) and JAR 2008 (1–2 orders of magnitude; covers both Cooper and Ferrante–Rackoff); Nipkow, *Linear Quantifier Elimination*, IJCAR 2008 / JAR 45(2):189–212 (2010) gives verified DLO, Loos–Weispfenning, Ferrante–Rackoff generically. HOL4 already has the execution substrate (`computeLib`, and the newer `cv_compute`) and precedent (`EVAL_ringLib` follows Boutin, *Using reflection to build efficient and certified decision procedures*, TACS 1997; Barras TPHOLs 2000). This is the natural route for `ferrack`/`mir` too (MIR: Chaieb, *Verifying Mixed Real-Integer Quantifier Elimination*, IJCAR 2006, LNCS 4130).
2. **Proof-producing ML with certificates** (gap: generic linarith-style front end, simplex): keep search untrusted, replay only certificates — exactly `fast_lin_arith.ML`'s `injust` (Farkas multipliers) and HOL4's existing `OmegaMLShadow` and `positivstellensatz` designs. For a modern simplex backend with certificate replay: Dutertre & de Moura, *A Fast Linear-Arithmetic Solver for DPLL(T)*, CAV 2006, plus the Isabelle-verified incremental simplex (Thiemann et al., *Verifying an Incremental Theory Solver for Linear Arithmetic in Isabelle/HOL*, FroCoS 2019) as a verified-kernel option. Argo (Böhme) shows the internal-SMT packaging.
3. **Certificate checking by normalization** (gap: none — already how both provers' Gröbner works; extendable): Harrison, *Automating elementary number-theoretic proofs using Gröbner bases*, CADE-21 2007; Chaieb & Wenzel Calculemus 2007. The same pattern (untrusted CSDP → Positivstellensatz certificate → ring-normalizer check) is Harrison, *Verifying nonlinear real formulas via sums of squares*, TPHOLs 2007 — already ported as `SOSLib`.
4. **Preprocessing/packaging** (gap: `arith` combinator, splitting, simp integration): pure engineering following `lin_arith.ML` + `arith_data.ML` — an extensible registry, `[arith]`-fact insertion, bounded case-splitting of `min/max/abs/div/mod`, and escalation `Boulton → Omega → Cooper`. No new theory needed; `IntDP_Munge` already contains the nat→int munging.

Key takeaways: (a) Isabelle's production `presburger` is proof-producing ML, with the verified reflected Cooper relegated to a `quick_and_dirty` oracle; (b) HOL4 is *not* missing Gröbner — Harrison's `Grobner`/`Normalizer` were ported in 2022 and back `INT_RING`/`REAL_FIELD`/`ringLib`; (c) HOL4's biggest real gaps are packaging (no `arith`-style escalating combinator — `bossLib.DECIDE` is still Boulton-1992 + taut) and the absence of any verified/reflected QE (Cooper, Ferrante–Rackoff, MIR), where the Chaieb–Nipkow reflection technique plus `computeLib`/`cv_compute` is the established closing move.
